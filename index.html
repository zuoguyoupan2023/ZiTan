使用说明

① 身份：顶部按钮切换「听障朋友 / 志愿者」，决定气泡颜色和快捷用语；称呼可在 设置 → 通用 自定义。

② 快捷用语：黄边 = 填入输入框继续编辑，无黄边 = 点一下直接发送；可在 设置 → 预设 增删改。

③ 打字 / 发图：底部输入框打字发送；「+」可从内置相册或手机相册发图；长按气泡可引用对方消息。

④ 语音输入：点麦克风说话，停止说话后自动结束识别；苹果设备与境外安卓可用浏览器识别，云端识别需在 设置 → 语音 → 语音识别 配置（支持微软 Azure / OpenAI 等）。

⑤ 朗读：开启顶栏喇叭后，发出的消息自动朗读；声音可在 设置 → 语音 → 朗读 选择并试听。

⑥ 大字号：顶栏 A+ / A− 调整全局字号，引用与翻译随正文同步缩放。

⑦ 倒置模式：设置 → 通用 → 文本方向选「倒置·正置混合」，听障朋友发出的文字和图片旋转 180°，对面朋友无需颠倒手机。

⑧ 翻译：点气泡旁「译」翻译消息；默认 MyMemory 免费，也可在 设置 → 翻译 配置 AI 翻译；直发预设中英互译秒翻。

⑨ 收藏 / 相册：点气泡左侧心形收藏；设置 → 收藏 查看，设置 → 相册 管理图片。

⑩ 全屏展示：点气泡全屏大字给对方看，左右滑动切换上一条 / 下一条。

⑪ 数据：聊天仅存本机浏览器；设置 → 数据 可查看历史会话、导出 JSON 备份。

字谈怎么用？

  1. 顶部选「听障朋友」或「志愿者」，决定快捷用语和气泡颜色。
  2. 快捷用语：黄边 = 填入输入框继续写；无黄边 = 直接发。
  3. 打字字号已放大，A+ / A− 可调。说话用键盘自带的语音键。
  4. 气泡外侧播放键可朗读这段话；顶部「喇叭」开时发送自动朗读。语音在「设置 → 语音」里选和试听。
  5. 点任意消息 → 全屏超大字；左右滑看上一条 / 下一条。

本地运行，内容不离开设备。对话和设置存在本机浏览器，刷新不丢。

欢迎使用字谈

三步开始面对面交流：

  1. 顶部选择身份：听障朋友 / 志愿者（决定气泡颜色和快捷用语）。
  2. 打字、点「+」发图，或点麦克风说话 —— 停止说话后自动结束识别。
  3. 点气泡全屏大字展示给对方；心形图标可收藏常用内容。

朗读、翻译、倒置显示等更多功能，见 设置 → 使用说明。
